앱 설정과 감사 기록을 한 트랜잭션에 저장합니다. 앱 변경·runtime 준비·workflow 생성의 버전과 전역 변경 잠금도 조건부 트랜잭션으로 검사합니다. Runtime의 UNKNOWN은 같은 작업이 관측될 때만 명시적 RECONCILE로 진행합니다. 이전 service가 보인다는 이유만으로 잠금을 풀지 않습니다.

## 실제 실행에서 확인한 차단

로컬 확인용 NGINX 앱의 이미지 실행 근거는 확인했습니다. 그러나 다음 검사를 통과하지 못했으므로 VERIFIED로 바꾸거나 마이그레이션을 시작하지 않았습니다.

- adapterProfiles
- environment:aws
- environment:gcp
- workloadActors

NGINX는 업무 정지·업무 검사를 구현한 데모 앱이 아닙니다. 통합 검사의 마이그레이션 서버·업무 참여자·업무 검사는 모의 구현입니다. 실제 데이터 이전 성능이나 무중단을 증명하는 검사는 아닙니다.

## 남은 외부 확인

- 실제 object 서버 2개 검사, Redis 스택 1개 검사, traffic 서비스 2개 검사는 연결 설정이 없어 미실행입니다.
- ECS 호출은 모의 클라이언트로 요청을 검사했습니다. 실제 AWS service 갱신·IAM·네트워크·Secret 주입은 배포 환경에서 추가 확인해야 합니다.
- GCP·온프레미스 자동 앱 기동 실행기는 없습니다. 이미 실행 중인 관리 앱은 인증된 heartbeat의 이미지 보고와 상태 검사로 연결합니다. 이미지 보고는 관리 프로세스의 선언입니다.
- DB 대상의 새 쓰기 후 복귀, 역방향 DB 복제, 전체 리소스 자동 롤백은 제공하지 않습니다. 기존 개별 리소스 복귀 계약을 유지합니다.
- 기존 프론트엔드 데모와 신규 앱 관리 API의 연결은 이번 백엔드 작업 범위에 포함하지 않았습니다.
